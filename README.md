
## Pasos rápidos (GitHub Pages)
1. Crea un repositorio llamado `TUUSUARIO.github.io` y sube estos archivos.
2. En **Settings → Pages**, selecciona la rama `main` y carpeta `/`.
3. Abre `https://TUUSUARIO.github.io/` en el navegador. ¡Listo!

> Cambia `destino@example.com` en `index.html` por tu correo real para el formulario.
